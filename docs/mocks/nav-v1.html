Correction: the alignment was already right, my mock was wrong

Logo left / links right is how the live nav already behaves — landing.css:127 sets .nav-links{margin-left:auto}. My previous mock dropped the .nav-links wrapper and put the links straight into .nav-inner, so they hugged the logo and none of the real link styling applied. That mock was not showing you the site. This one uses the exact production markup.

Same cause for the underlines you just spotted: landing.css sets a{text-decoration:none} as a base rule, and my extraction of the nav styles skipped it, so the browser fell back to its default underline. The live nav has never been underlined. Fixed here.
